# MERN Todo Application

A simple full-stack Todo Application developed using the MERN stack.

## Project Overview

This project allows users to manage their daily tasks. Users can add new tasks, edit existing tasks, mark tasks as completed, and delete tasks.

The project demonstrates frontend development with React, REST API communication using Axios, backend development using Node.js and Express.js, and database interaction using MongoDB and Mongoose.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios

### Backend
- Node.js
- Express.js
- REST API
- Mongoose

### Database
- MongoDB

## Features

- Add a new task
- View all tasks
- Edit a task
- Mark a task as completed
- Delete a task
- Store tasks in MongoDB
- Retrieve tasks from MongoDB
- Responsive user interface
